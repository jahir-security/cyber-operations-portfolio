# Fundamentals of Firewalls - [11-26-2026]

## What This Covers
This lab introduces firewalls and explains several types of firewalls. It also provides basic practice in configuring firewalls in Windows using Windows Defender Firewall. It provides an introduction to Netfilter and UFW (Uncomplicated Firewall).

## Key Concepts
* Understanding the different types of firewalls -
  * Stateless firewall
  * Stateful firewall
  * Proxy firewall
  * Next-Generation Firewall
* How to set up basic inbound and outbound firewall rules in Windows Defender Firewall.
* Basic understanding of Netfilter and UFW.

## Commands and Tools Used
```bash
# Windows Defender Firewall
  * setting advanced rules for inbound and outbound traffic
  * learning how to sort rules based on the local port

# linux ufw commands
sudo ufw status

sudo ufw enable

sudo ufw deny 22/tcp

sudo ufw default allow outgoing

```
