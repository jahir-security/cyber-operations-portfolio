# Gobuster - [11-22-2026]

## What This Covers

This lab covers Gobuster, an open-source reconnaissance and enumeration tool written in Go. It focuses on discovering hidden web directories, files, DNS subdomains, and virtual hosts using wordlists and brute-force enumeration techniques. I configured the AttackBox environment by updating the local DNS resolver configuration and restarting the Dnsmasq service to resolve the lab domains. I explored Gobuster's help menu, command structure, and commonly used flags before working with its three main enumeration modes: dir, dns, and vhost. I practised directory and file enumeration, including searching for specific file extensions, followed by DNS subdomain discovery and virtual host identification. The lab also covers HTTP response status codes, response length filtering, redirects, and false-positive identification. Finally, I applied these techniques to the offensivetools.thm environment to discover interesting directories, investigate JavaScript files, enumerate subdomains, and identify virtual hosts responding to HTTP requests.

## Commands/Tools Used

```bash
# Gobuster Help:
gobuster --help

# Directory Enumeration Help:
gobuster dir --help

# DNS Enumeration Help:
gobuster dns --help

# Virtual Host Enumeration Help:
gobuster vhost --help


# AttackBox DNS Configuration:
sudo nano /etc/resolv-dnsmasq

# Add the Lab Machine IP as the First Nameserver:
nameserver MACHINE_IP
nameserver 169.254.169.253

# Restart Dnsmasq:
 /etc/init.d/dnsmasq restart

# Verify DNS Configuration:
cat /etc/resolv-dnsmasq


# Directory and File Enumeration:
gobuster dir -u "http://www.example.thm" -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -r

# Directory Enumeration with Specific File Extensions:
gobuster dir -u "http://www.example.thm" -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x .php,.js

# Skip TLS Certificate Verification:
gobuster dir -u "https://www.example.thm" -w /path/to/wordlist --no-tls-validation


# DNS Subdomain Enumeration:
gobuster dns -d example.thm -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt


# Virtual Host Enumeration:
gobuster vhost -u "http://MACHINE_IP" --domain example.thm -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain --exclude-length 250-320

```
